# 📚 Study Planner App

A simple full-stack Study Planner web application built using **FastAPI**, **SQLite**, and **HTML/CSS/JavaScript**.

---

## 🚀 Features
- ➕ Add study plans (subject + hours)
- 📋 View all plans
- ❌ Delete plans
- 💾 Data stored using SQLite database
- ⚡ Fast backend using FastAPI
